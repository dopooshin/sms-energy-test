Technical Architecture

技术架构说明

设备端 (DTU 模块) → TCP/IP 网络 → 数据服务器 → Web 前端展示

支持协议

Modbus TCP / 自定义 TCP 协议。
后续可扩展 MQTT、WebSocket 实时推送与 HTTP 轮询等方式接入。

数据字段

设备 ID、温度、电流、电压、运行状态、运行时间、故障码等。
字段随设备型号扩展，统一由数据服务器解析后下发前端。
